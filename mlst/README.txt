MLST reviewer entry for the frozen hydrogel continuation study

One command from the public repository root

python mlst/reviewer_replay.py --repo-root . --output-dir NEW_DIRECTORY

Requires Python 3.10 or later and the standard library only. The command
refuses an existing output directory. It first verifies a fixed subset of
the original saved ledgers and arithmetic programs against hashes taken
from the 778d9372a9c5847205db3289e81a3c73aee45962 checkpoint manifest.
The separately registered saved-UQ program is also pinned. This subset
does not depend on later updates to the repository's root MANIFEST.json.

What is reproduced
The existing reproducibility/replay_tables.py reconstructs the original
development-score tables from public score ledgers. The saved-UQ script
reorganizes the original external score scalars for the three probabilistic
methods and four sources. A table/figure crosswalk maps the original labels
to the MLST-focused manuscript. Remapped Main Tables 2, 3 and 4 and SI
Tables S11 and S12 are written as CSV files, with full-precision source
outputs retained. Main Table 1 describes data roles and is not a numerical
experiment. Figures remain in the archived manuscript/graphics collection;
their rendering is not regenerated by this scalar-only command.

A success receipt is written only after both child programs exit
successfully, the saved-result validation passes and input hashes still
match. Child failures retain their transcript and a failure receipt. They
do not produce a success receipt. Old files are never overwritten.

What this command does not do
No model import, fitting, inference, reconstruction of measured response
arrays, target scoring, conformal calibration, threshold selection or
new independent material validation occurs. The deployment weights were
fitted using all 25 P curves and lawful six-anchor records of 20 S curves;
they are not the original leave-one-formulation-out models and must not
be used to recreate development evaluation by predicting those same P
records. Full original raw/processed-input, reference-fit and out-of-fold
law replay remains separately scoped.

Public versus local resources
This public directory contains scalar results, arithmetic programs and
evidence needed to inspect those calculations. The larger local research
packages also retain scientific execution assets and upstream workbooks
subject to their source terms. They have a different redistribution scope.
Public visibility is not a new software/data/manuscript reuse license.
Original asset terms, processed-input access, author declarations and
AI-use disclosure require author verification. No model weight, raw
measurement or restricted upstream asset is uploaded by this command.

How to interpret UQ
CRPS, RMSE, coverage, interval width and interval score measure different
aspects of prediction. Native-curve zero-coverage and all-target-band counts
are descriptive and do not certify independent preparation trials or
simultaneous coverage. The existing four sources are consumed transfer
stress tests, not untouched calibration or same-domain confirmation data.
All original failures and source identities remain in the calculation.

Guard fixtures
python -m unittest discover -s mlst -p test_reviewer_replay.py -v
python -m unittest discover -s mlst/saved_uq -p test_replay_saved_uq.py -v

The first suite checks tampered input, missing input, tampered bindings,
existing output and an explicitly mocked failed child without launching
replay subprocesses. The second uses
invented scalar scores to test non-naive group weighting and identity
guards. Neither suite is evidence of predictive performance on materials.
