本轮拟补的是未来预测带的分组校准与确认流程，不另造一个更复杂的分布。25个P配方及46条外部已评分曲线均已被研究过程使用，不能转而称为新的校准集；同一材料的不同遮挡、剪切率位置、重复数字化或重抽样也不能增加独立材料数。20个S配方目前只有合法锚点，受保护空白不是可用校准标签。

2. 首先确定“新”的是哪一层

若主张“新配方泛化”，一个独立单位应包含该配方全部相关制备、曲线和查询，且配方及物理来源链应与旧开发集、校准集、确认集按协议隔离。不能把同一个配方的一条曲线放校准、另一条放确认。

若主张“已知配方的新制备批次泛化”，可以事先允许配方相同，但必须确为新的独立物理制备批次；同一旧制备样品的重复扫描、同一原始运行的复用、图表重绘都不是新批次。该主张弱于新配方泛化。不要为了容易划分而混合两种目标。

不同DOI、文章或仓库名称不能证明材料身份独立，更不能自动证明数据可交换。来源台账是必要的身份审计，但不是统计假设的替代品。新组与校准组必须来自所声明的同一测量/入组/查询政策，温度、材料状态、剪切方向和曲线数量政策均要登记。

3. 把整个独立组压成一个分数

令 U_i 为整个独立物理组；c表示该组内预先规定的曲线/查询组合，j属于该组合的有限原生隐藏目标集合J_ic。模型只接收合法锚点与已允许条件，输出自然对数黏度的预测均值mu_icj和正尺度sigma_icj。设

  y_icj = ln(eta_icj / eta_unit),
  S_i = max_{c,j} |y_icj - mu_icj| / sigma_icj。

这里的sigma必须有限、严格大于0，并由封存模型在不读取隐藏目标的前提下给出。它是非一致性分数的尺度；共形覆盖并不要求它恰好等于真实条件标准差。

每个U_i只产生一个S_i。组内可以有相关曲线、有序剪切率和多个遮挡，完全不需要把它们假设为独立，也不要求剪切率位置可交换。把全部固定目标取max，使“该组全部目标都被带覆盖”成为一个事件。若只要求一条主要续接查询，就只在事前规定的主要查询上校准；若希望同时覆盖多个查询，必须在同一个组分数中包括该有限查询族，通常带会更宽。

曲线数或目标数可因组而异，但整组对象（包括组大小与查询政策）在校准组和未来组之间仍须满足可交换性。校准时每组一条曲线、部署时每组无上限增加曲线，不自动继承原来的全组覆盖结论。

这属于普通split conformal在整组对象上的应用，不是声称实现了HCP算法。Lee、Barber和Willett的分层论文提醒我们：把相关层级数据铺平后直接当作独立样本一般不成立；我们的做法不使用其组内交换性或二阶覆盖结论。
来源：https://arxiv.org/html/2306.06342v4 （实际读摘要、1.1、2.1及2.2开头）。

4. 必须使用准确的秩，不是随意的分位数插值

给定n个新独立校准组、预先设定的0<alpha<1，令

  k = ceil((n+1)(1-alpha))。
  q = 校准S按从小到大排序后的第k个值，若k<=n；
  q = +infinity，若k>n。

边界用“<=”，重复分数保留。不要删除并列值，不要进行线性插值，不要把k强行压回n，也不要用最大有限校准分数替代应有的无穷。

为避免浮点ceil在整数边界多加1，协议把alpha写成准确十进制字符串或分数。若alpha=a/b，则

  k = ((n+1)*(b-a)+b-1) // b。

例如n=9、alpha='0.70'时k必须等于3，不能因二进制浮点的1-0.7而误算为ceil(3.0000000000000004)=4。软件直接取sorted_scores[k-1]。示例伪代码中的np.quantile(...,k/n,method='higher')也不能不经核对照搬：不同样本分位数网格未必对应第k个秩。数学定义本身没有这种歧义。

90%带（alpha='0.10'）得到有限q的最低代数条件为n>=9；95%时为n>=19。它们只是“有限带是否可能”的门槛，绝不是建议样本量，更不代表9个组足以精确证明科学可靠性。样本量还须结合物理容差、预期差异、确认精度和可实施预算事先确定。

空校准集不能产生有限校准成果。接口应返回NO_CALIBRATION_UNITS/NOT_CALIBRATED；若展示形式上的全空间回退，也必须标明“无信息”。非空但k>n时返回无穷带，并明示INSUFFICIENT_FOR_FINITE_BAND；不能退回1.645或1.96倍sigma后仍称其为共形校准。

5. 可以证明的只有这个覆盖结论

构造每个目标的带

  B_icj = [mu_icj - q*sigma_icj, mu_icj + q*sigma_icj]。

如果在给定冻结训练与所有事前选择的条件下，n个校准整组对象和一个未来整组对象可交换，则

  P(未来组全部预定曲线/查询的全部有限隐藏目标都落在B中) >= 1-alpha。

证明很短：对每组应用同一个分数映射，得到可交换的S_1,...,S_n,S_new。仅在证明中随机打破分数并列，新分数的秩在1,...,n+1中均匀。秩不超过k时，一定有S_new<=S_(k)，因此包含边界的实际带覆盖概率至少为k/(n+1)>=1-alpha；k>n时全空间带显然覆盖。实现无须添加随机噪声。并列值会使确定性带更保守，所以不声称覆盖率恰等于90%。

这是对“校准组与未来组随机抽样”的边际覆盖结论。它不保证每一种化学配方、每一个来源、每一组锚点条件下都覆盖90%；也不保证对某一已经固定的校准集，其实际条件覆盖率必然>=90%。有限确认集的观测覆盖率低于90%并不与边际定理自动矛盾。无条件下共用同一个q会使多个确认覆盖指示量相关；若确认组确为iid抽样，则固定q之后可用二项区间估计该固定带的条件成功概率。仅凭可交换性不应添加iid精度承诺。

保证仅限预先登记的原生有限网格。画线连接两点的带不等于对两点之间整条连续曲线也有共形保证，向域外延伸同样不受保证。

经典来源：Diquigiovanni等的正尺度最大残差及多变量函数带，https://arxiv.org/html/2106.01792v1 ，重点读3.1；Lei等split conformal与训练集确定的局部尺度，https://arxiv.org/html/1604.04173v2 ，重点读2.2和5.2；Angelopoulos与Bates的附录D明确给出秩和无穷回退，https://arxiv.org/html/2107.07511v6 。这部分是规范使用已有原理，不应包装为新理论。

6. 黏度正值、异常和机器范围

本说明使用自然对数，并把黏度单位固定在eta_unit中。原尺度带是[eta_unit*exp(l), eta_unit*exp(u)]，单调变换保持同一个覆盖事件。若冻结模型实际用了log10或其他坐标，必须登记一致转换，不能直接把其数字当自然对数。q无穷时对数带为整条实线，原尺度是所有正黏度(0,+infinity)。

mu、隐藏测量和标准化残差须有限，sigma须有限且严格正；原尺度黏度和剪切率须正且有限。若sigma下溢到0，或残差除法上溢，应明确数值失败，不能偷偷删除该组或临时增加epsilon。若确实要用尺度下限，该规则必须在训练/校准之前固定并对所有组相同。

q=0在校准分数全为0等情况下可以出现，数学上允许，但不能据此解释为材料没有不确定性。严格JSON不能保存NaN或Infinity；建议q=null、q_is_infinite=true及明确status。有限对数边界在exp中越出机器范围时，保留稳定的对数边界并标记原尺度表示限制，不能把截断数称为真实有限边界。

7. 校准带不等于校准分布

带只给出一个集合，不能唯一确定密度、相关性或CRPS。因此Gaussian的CRPS和联合对数密度仍来自原封存Gaussian预测，不受q影响。以log黏度为响应，原Gaussian边际的CRPS为

  z=(y-mu)/sigma,
  CRPS = sigma*[ z*(2*Phi(z)-1) + 2*phi(z) - 1/sqrt(pi) ]。

若把协方差乘上q的函数，就新增了一个分布模型；这种模型是否改善CRPS或密度需要单独训练和验证，不能从集合覆盖定理中推出。

区间覆盖、宽度和区间分数可以另外报告。对有限区间[l,u]，

  IS_alpha = (u-l) + (2/alpha)*max(l-y,0) + (2/alpha)*max(y-u,0)。

但这里alpha针对“整组全目标同时漏覆盖”，并不是每个点的等尾边际误覆盖水平。因此点平均IS_alpha只作宽度/漏覆盖权衡的描述性诊断，不宣称其是该组带的最优边际严格适当评分。无穷带的宽度和IS为无穷；须显式分支，避免0*infinity或infinity-infinity变NaN，更不能只删掉无穷带后报告有限均值。

8. 主CRPS如何按实际剪切率范围加权

主要任务限定为六个低剪切率锚点之后的原生网格续接。令gamma_star为最高合法锚点剪切率，只选原先登记且gamma_j>gamma_star的隐藏原生目标，位于固定物理支持域中。令t_j=ln(gamma_j/gamma_unit)，排序后t_1<...<t_m，主要积分分数要求m>=2。

原始梯形权重：
  a_1=(t_2-t_1)/2,
  a_m=(t_m-t_(m-1))/2,
  a_j=(t_(j+1)-t_(j-1))/2，1<j<m。
令w_j=a_j/(t_m-t_1)，则各权重正且总和为1。

  L_curve = sum_j w_j * CRPS_j。

这只是原生目标点损失在[t_1,t_m]上的归一化梯形汇总，不是声称测量到了连续损失函数。只用目标点的端点梯形没有覆盖“最高锚点到第一个隐藏点”的间隔，应另报gap=t_1-ln(gamma_star/gamma_unit)、其物理端点、实际评分跨度t_m-t_1及目标点数。不要给锚点凭空补一个损失或把这一段缺口藏掉。

m=1的积分跨度为0，不能任意构造半个区间。预先规定它不进入主要积分分数，可以另报带single_point标签的单点CRPS。m=0则是入组前可识别的目标不足，登记原因和数量。重复坐标必须有事前确定的重复测量汇总政策，否则拒绝；原生目标不能是用插值得到的新“测量”。严格高于最高锚点、支持域、单位与排序规则都应在看隐藏结果前确定。

同一独立组若有多条曲线/多个查询，先按事前固定权重在组内汇总，再对独立组等权平均。所有强基线共用同一入组材料、锚点、原生目标、端点和权重。保留各曲线跨度，因为即使均归一化，不同覆盖范围仍对应不同科学问题。比较时以每组配对差d_i=L_i(model)-L_i(baseline)为基本单位，不以33个目标点或多个掩码扩充N。

9. 真正启动未来实验的顺序

第一步：不看新隐藏结果，核定来源和物理父子身份，区分新配方与新批次，登记旧来源排除表。当前没有新组，不能用占位数据填实。

第二步：登记模型选择、物理状态、合法锚点、有限目标、主要查询、alpha、强基线、组数和分配、评分、容差、停止规则。实际可接受误差/可得组数未确定时保持null，方案不能被描述为已经激活的科学预注册。

第三步：冻结实际UTC、源码/模型/输入哈希和分组元数据，仅通过合法锚点产生Gaussian预测，保存预测哈希；尚不看任何新隐藏目标。

第四步：仅揭示校准组目标，计算每组一个S、准确的k及q，保存全部失败和无穷状态；不改模型、换掩码、挑最窄带或重新划分校准与确认。

第五步：冻结校准产物与确认组的带（或可确定重建其带的全部输入/哈希），让独立核查者确认身份隔离、秩、尺度和目标定义，再揭示确认目标。

第六步：只揭示一次确认目标，报告原Gaussian评分、带的独立组同时覆盖、点/曲线诊断、所有失败及与强基线的配对结果。确认失败同样保留。若据此修改模型，这批材料即成为开发证据，下一次确认须再换新组。

若同时评估多个事前固定的方法，各方法各自的边际保证不等于“所有方法一起覆盖”的保证；用同一最终校准标签挑优后，入选方法也不自动继承单一固定分数保证。需要额外选模集、新校准集或事先规定的家族控制。结果差就事后删组、加拒绝门、换曲线范围，会破坏原协议。固定输入域筛选若要使用，必须在校准和未来组上对称实施并明确其接受人群；简单共形带没有自动给出安全拒绝保证。
