Abstract local repair process demonstrator

The subject is a computational process: local sensing, neighbour communication,
blank-region activation, feedback repair and stabilization. It is not a model of
an animal, biological tissue or any particular material. All values are synthetic.

Read PROCESS_EXPLANATION_ZH.txt. Selected process image:
demo/output_r2/REPAIR_PROCESS.png. Probability illustration:
demo/output_r2/REPAIR_PROBABILITY.png.

The core has three small modules: graph/observations, local repair/sampling,
and fixed experiment/reporting. With the declared NumPy/Matplotlib versions:
python demo/run_process_demo.py --output-dir NEW_DIRECTORY
Existing output directories are refused. No download or material data is needed.
