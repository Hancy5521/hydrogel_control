查询学习概率码：资源包说明与算法阅读指南

本文件在封装源码准备期间起草，并在本阶段开发终点评价闭合后补入失败结果。它说明实际冻结方法与审阅路径，不冒称已经达到强基线。详细性能请阅读本包 stage/score_once/AGGREGATE.json、independent_audit/SCORE_SAVED_AUDIT.json及根代理随后形成的结论。数值门通过、真实反馈发生及资源齐全，不能替代效果证据。

一、这套程序解决什么
最初问题是材料性质稀疏、不同配方只有少量已测性质，如何保留性质分布的不确定性并利用少量真实核验改善缺失性质的概率生成。最新开发试验把问题限定为公开计算材料报告的一项bulk性质；不是新增水凝胶湿实验，也没有证明任意材料、任意缺失mask的联合生成。

程序先用历史真实报告构造完整经验参考F，再学习很小的CDF质量修正。低维的是修正方向和风险相关统计，不是把完整材料分布强制压成低秩。每个原参考正概率原子仍存在。原始数据中观察为空白的目标只在被实际抽中后读取；预测值不加入“真值训练集”。

生物启发可描述为：先在已有网的局部发现问题，核验后修复；修正后的状态改变下一步核验资源分配。当前四批真查询形成反馈，但参考支持F808在本轮固定。不能把基线RF936更新说成主候选已经扩展支持；不能将这条反馈链直接命名为完整Eigen超循环。支持扩张、持续自增长和进一步跨材料泛化仍是新的待验证工作。

二、数据与角色
历史808个不同原始组：旧RF296原始训练记录与后来已消费的512组。旧原始X从真实历史恢复，逐坐标匹配原RFfloat32状态，不从舍入后的X反推原值。它们是开发数据，不是独立确认。

未来6279组经过全部原始身份、配方成分、JID/MPID传递闭包核对，排除此前1920消费组与整个dielectric来源的所有别名兄弟。先按SHA256(query_code_confirm_v1|ID)永久预留1024组，再从余下5255按SHA256(query_risk_code_v1|ID)选本次512开发组，另留4743开发组。每组采用原eligible索引最小代表，所有原始兄弟保留同角色，不依据新目标值重选。

1024确认组的身份/成分metadata已经用于分组，额外材料属性X/Y没有向本轮模型披露。公开源表本来含有这些属性，本资源包若包含原表是为了完整性与来源审阅；这是软件访问契约，不是密码隐藏。不得在未来方法冻结之前主动查看其属性做调参，再称独立确认。

512开发组先冻结预测，再用真实随机查询128个标签，余下384构成共同终点。128查询不混入主终点评价以抵消剩余预测损害。整个512消费后不重切、不在该确认结果上追参，再称新确认。

三、概率模型与数学
固定PIT边界：0,.05,.5,.95,1。每个参考F_i按这四段的概率质量分解为F_ij，p=(.05,.45,.45,.05)，F_i=sum_j p_j F_ij。

令h_i=(F_i1-F_i4,F_i2-F_i4,F_i3-F_i4)。组成上下文g固定为S/Se/Te原子分数，h~_i=((1-g_i)h_i,g_i h_i)。两组四维simplex端点给出8个质量变量、6个有效方向。theta=.01p+.99s，保证每一原参考正质量原子仍保持正质量。最终CDF为H_i=F_i+h~_i' beta。

原生CRPS风险差：
 CRPS(H_i,Y)-CRPS(F_i,Y)=beta'Q_i beta+2 beta'c_i(Y)
 Q_i=int h~_i h~_i' dz
 c_i(Y)=int h~_i(F_i-1[z>=Y]) dz
Q_i及c_i对所有实数Y的范围由冻结预测确定，真实Y只进入被查询点的c_i。该低维c_i对固定修正族的CRPS风险已足够；不宣称它对任意高维任务充分。

当前剩余池的估计学习目标：
 [beta'Q_R beta+2 beta'P_range(Q_R) Chat_R
  +.25(beta-beta_prior)'Q_R(beta-beta_prior)]/|R|
Q_R是剩余预测的Gram之和。精确Fraction RREF区分真正零方向与极小非零方向，不加ridge、也不拿特征值容差直接删小方向。Chat_R投影只是几何相容的点估计，不是置信序列、方差降低定理或无风险改进保证。

四、真实反馈如何发生
先以历史808组做固定5折整组OOF RF。三个先验头global/context/Beta用相同OOF，不根据当前目标自动挑组成描述符。再拟合RF808，冻结全部512参考、先验、真值无关几何。

冻结完成之后才向操作系统请求实际随机种子。每32次查询固定当前theta，每步计算所有剩余对象的精确概率：
 q_i=1/4*(1/n)+3/8*(c范围宽度归一)+3/8*(当前候选相对参考CRPS差范围宽度归一)
零和项按均匀分配。所有对象始终有正概率。按有理数公共分母生成整数票据，先把所选身份、q、票据、剩余索引和当前theta持久保存，关闭文件后才释放该对象原始Y。

使用冻结范围中点m_i，逐步全池统计：
 Z_t=sum_all m_i+sum_past(c_i-m_i)+(c_I-m_I)/q_I。
累计Z的均值减已查询c得到剩余估计。冻结全池的逐步条件期望性质，不等于给定随机剩余池、投影与拟合后的最终估计仍条件无偏。插件目标下降不保证真实CRPS下降。

共4批各32次查询，实际更新4次修正势。批后学得的theta影响下一批查询概率，因此并非只在历史数据上训练一个永不更新的校准头。同时保存普通单位权重queryERM控制；自适应样本上的普通ERM不是无偏activeERM，同查询控制也不是查询策略的因果消融。

五、v1失败与v2数值修正
v1数值门及失败原件完整保存。v2仍是一次SLSQP，在已选active面只作一次精确KKT线性修正，不换面、不多起点、不按材料效果改参数。精确候选仅作证书；实际USED参数经过有限float往返、精确归一后再核同一目标、可行性和KKT，限制后续随机票据分母膨胀。失败回到声明的先验，同时保留原始解和失败诊断。v2用同组合成例回归通过，不是第二组材料确认。

六、基线和比较
模型调用固定10次：OOF RF5、RF808一次，以及查询128后共同936真标签的RF936、GP936、CRPSForest936、官方NGBoost936四次。校准/修正QP和Beta五个起点另计，不把它们或单棵树当独立实验。

最终同384对象共十种分布：F808、priorglobal、priorcontext、Beta、geometryRiskCode、plainQueryERM、RF936、GP936、CRPS936、NGBoost936。前四只用808标签，是低信息消融。主方法是否达到强基线应主要看同808+128标签的完整936控制，而不是只胜过低信息参考。

RF/GP/NGBoost使用旧历史固定的正尺度变换；CRPSforest用相同10项原始特征。固定可逆尺度不增加标签信息，数学上的树排序/可实现分区不变。RF内部float32与CRPS树float64数值路径不同，独立状态审计不据此声称两算法相同。

NGBoost为官方稳定0.5.11，Normal+CRPScore，500 stages、learning_rate=.01、深度3 friedman_mse树、natural_gradient=true、minibatch=1、colsample=1、seed20261107、tol=1e-4，无评估集早停。保留实际stage数、所有警告、init_params/scalings/col_idxs和每阶段两参数树，独立审计无需导入NGBoost即可重建推断。

七、如何评价
十种完整CDF与确定性摘要必须先冻结，再一次读取384剩余目标。CRPS为主指标；点预测均值的RMSE/MAE、80/90/95等尾覆盖和平均宽度为副指标。经验分布用精确累计概率的广义逆，Normal用解析逆CDF；不靠随机采样近似分布来偏袒某一法。

独立审计不导入SUT、不调用训练模型predict，而从JSON森林/GP/NGBoost状态、经验质量、真实查询和冻结预测重算。它验证保存状态的推断、算术和信息公平，不认证超参数最优或每次树训练的全局最优。

八、资源包结构与可移位审阅
stage/：当前阶段科学原件的原字节。包括metadata、initial、query、updated、final、score各阶段（以实际存在为准）、registration、core v1/v2、数值门、独立审计、研究限定与固定方法说明。原JSON内的历史绝对路径不会为了可移位而改写，故其哈希与冻结链仍成立。
assets/：主计划和实际收据引用的外部输入、依赖原字节，按ASCII哈希路径归档。
RESOURCE_MAP.json：历史绝对路径到本包相对路径、SHA256和字节数的显式映射。
MANIFEST.json：所有有效载荷文件的相对路径、原来源、SHA256和字节数。MANIFEST自身SHA另存，避免循环自引用。
review_saved.py：先verify检查字节与映射，或在新的review_runs/真实UTC目录复跑独立saved-only审计。它仅将独立审计的文件读取/哈希和gzip读取重定向到映射资源，不改变注册原件、预测数组、优化器或数学。默认不读取本机旧H盘路径，不训练、不重新抽种子、不导入SUT。

建议先运行 python -X int_max_str_digits=0 -B review_saved.py verify。
需要独立数值复核时，安装requirements_review.txt所列NumPy/SciPy，再执行 review_saved.py audit --phase final 或scores。其他已完成metadata/initial/queries审计可按需复跑，输出另存并标实际UTC；initial较慢且生成独立cache。已保存的PASS仍是原审计，不会把这次复跑计成新材料确认。

原训练脚本保留用于理解与未来复现计划。不要直接在移位包中把旧plan改成新绝对路径并假称哈希仍有效；也不要在旧输出目录重新fit。重现新的训练需要新UTC、资源映射后的新计划、新输出目录和适当的数据访问角色，历史seed只用于审阅原票据，不伪称新实验的OS随机抽取。
