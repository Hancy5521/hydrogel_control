# 新树脂开发试验的独立解释与下一步证据门

日期：2026-11-09。核读起点实际 UTC 04:00:47（北京时间 12:00:47）；本文件解释已经保存并独立审计的主试验、物理控制和早期影响 pilot，没有拟合、改参数、重切配方、重算生产评分或读取未来 35 个 runs 的 CSV 黏度。下述新通用克里金方案仍属于开发诊断；此文不预写其成功。

## 1. 当前结论

这次确实产生了材料补全证据，也暴露了一个重要改进位置：**材料曲线的锚点布局有很大作用，而旧水凝胶模型的趋势/尺度不能直接当作新树脂的可靠概率参考。** 新接口、冻结预测、同信息控制与独立核查值得保留；但当前还不能声称复杂采点或早期修复机制优于领域强基线。

原 MLST 水凝胶成果不因此作废。它与本次未固化光敏树脂/HGM 来源、开发配方、单位和测量过程不同；本次是转移压力测试。既不能把它写成新水凝胶独立批次成功，也不能凭该来源上的失败否定原限定任务的既有结果。

## 2. 主终点改善成立，但大效果不能全部归给新机制

原登记主比较为冻结曲率 Gaussian 的 expected-CRPS 六锚点布局，相对于固定前六点，在同一 tail panel（native ranks 18–25）上的 recipe 宏平均 CRPS。

| 比较 | CRPS（log 黏度坐标，越低越好） | 90% 区间覆盖 | 平均区间宽度 |
| --- | ---: | ---: | ---: |
| 曲率 Gaussian，前六点 | 0.69214636 | 0.516667 | 0.839781 |
| 曲率 Gaussian，expected-CRPS 布局 | 0.06514786 | 0.608333 | 0.174033 |
| 曲率 Gaussian，nearest-target 布局 | 0.06296788 | 0.616667 | 0.174103 |
| 曲率 Gaussian，max-variance 布局 | 0.06215932 | 0.658333 | 0.176151 |
| GP，expected-CRPS/nearest-target 相同集合 | 0.07095484 | 0.533333 | 0.192143 |
| 幂律 Student，与曲率 expected-CRPS **相同六点** | 0.04970998 | 0.950000 | 0.361776 |
| 幂律 Student，nearest-target 六点 | 0.04448969 | 0.916667 | 0.302234 |

主差值为 **−0.6269984962**，正确方向是改善。三个 recipe 都改善，但改善幅度差异很大：`0_13gcc_40%` 为 −0.00782790，`0_31gcc_10%` 为 −1.63633843，`0_31gcc_40%` 为 −0.23682916。约 **86.99% 的绝对总改善**来自第二个 recipe；不能把宏平均的大差值叙述为所有组同样大幅提升。

更关键的是，固定前六点到 tail 的外推距离远，nearest-target 只是将四个新增读数移到允许候选域中最接近 tail 的 ranks 14、15、16、17。独立读取已经冻结的 mask 发现：**十五条曲线上 GP expected-CRPS 与 nearest-target 的六点集合全部相同**。因此在该候选域与评分 panel 下，GP 的复杂效用规划没有展示超过简单几何的选择收益。

曲率 expected-CRPS 的零基索引十五条均为 `[0,1,16,13,14,12]`，与 nearest-target 的集合 `[0,1,13,14,15,16]` 只差一个点。它并未优于 nearest-target，亦未优于当前 max-variance。现有证据支持“预算内测点位置重要、旧部署前六点不适合该转移任务”，不支持“新的采点算法已经胜过简单布局”。

这些比较的关键优势在于：固定的八个目标从未因查询而被移出评分；所有模型每次只用自己的六个真实读数，不以把困难点变成已知值而人为降低目标分数。

## 3. 强物理控制揭示问题，不是要求推翻完整协方差

幂律控制拟合 `ln η = β₀ + β₁ ln γ + ε`，使用每个方法已有的同六个读数，不额外看 tail。其后验预测保留回归参数与残差尺度的不确定性，df=4 的联合 Student 分布；不是靠最终目标调出来的区间放大系数。

同曲率 expected-CRPS mask 下，幂律的 recipe 宏 CRPS **0.04970998** 好于曲率模型的 **0.06514786**。不过曲率模型在其中两个 recipe 更好，而在 `0_13gcc_40%` 明显失败：

| recipe | 曲率 expected-CRPS | 同 mask 幂律 Student | 曲率模型的 90% 覆盖 |
| --- | ---: | ---: | ---: |
| 0_13gcc_40% | 0.12930189 | 0.03591771 | 0.075 |
| 0_31gcc_10% | 0.02167663 | 0.03319530 | 0.925 |
| 0_31gcc_40% | 0.04446508 | 0.08001694 | 0.825 |

旧协方差产生近乎固定的窄区间，不能表达如此不同的 recipe 误差尺度。其宏覆盖 0.608333 明显不足；幂律的 0.95 则是当前小开发样本的经验覆盖，不应升级为已经证明的可靠校准。约五个 runs 与每条八个相邻目标存在相关性，不能把 120 个点当作 120 个独立材料做精确覆盖保证。

同时，曲率 expected-CRPS 的联合 NLL/维约 **−2.60301**，比同 mask 幂律的 **−1.33690** 更低。负 NLL 对连续密度是合法的。该结果说明各评分关注的对象确有差别：当前 Gaussian 的完整跨位置依赖在联合密度上仍有价值，而其边缘误差和区间可靠性不足。不能只拿 CRPS 或只拿 NLL 中对自己有利的一项宣告全面胜出。

因此，下一步合理方向是**用实际六锚点识别当前曲线的物理趋势和尺度，同时保留原完整相关结构作为 shape**，而不是立即把原完整协方差丢掉、加更多混合分量或在旧 θ 上反复搜索。

## 4. 早期影响 pilot 提供的是一个明确负例

H3 的规则在目标揭示前登记：两个升温 dev recipe 的十条 runs 学一个归一化候选方向，按固定 0.05 更新并裁到原参数盒；另一降温 dev recipe 的五条 runs 提供低剪切率 sentinel。训练/检查读数仍来自固定前六锚点，不增加真实读数预算。

实际方向导数为 **−0.00341194**，预警判为无一阶有害信号；一步之后 sentinel 条件 NLL 确实改善 **−0.00162637**。这支持局部导数在它实际检查的位置与损失上的数值解释。

但低剪切率 sentinel 通过并没有保护高剪切率 tail：该 sentinel recipe 的 tail CRPS 从 **0.28129424** 变为 **0.28153059**；另两个 recipe 也恶化。门控接受了该更新，因此 gated 与 candidate 相同。该方向没有展示补全收益，也没有展示成功筛出有害 tail 更新。

这不是导数实现错误的证据。`∇L_S·d` 只针对 sentinel 位置的条件 NLL；远端目标与 sentinel 的观测几何、响应敏感性及评价指标不同。一阶正确也不蕴含另一个区段的评分改善。这里只检验一个候选方向，不足以估计预警器的总体精确率或漏报率；热历史与 recipe 身份亦混杂，不能据此解释升温/降温的因果差异。

本负例应原样保留。下一轮不通过改步长、换 sentinel 点、换 held-out recipe 或换目标来“救”这个已消费 pilot。先处理趋势/尺度错配，比继续加预警规则更有证据依据。

## 5. 下一有界诊断：物理趋势与尺度适配，加冻结完整 K shape

root 已明确：新模型的均值采用纯物理设计 `Xβ`，其中 `X=[1,lnγ]`；不额外保留冻结曲率的非线性均值。相关 shape 只允许两个候选：冻结 GP 的完整 K，或冻结曲率 Gaussian 的完整 K。旧 θ、K 超参数和原 MLST 文件不重新训练。

对六锚点 O，令 `A=X_OᵀK_OO⁻¹X_O`，使用 GLS 得 `β̂=A⁻¹X_OᵀK_OO⁻¹y_O`，残差 `e=y_O−X_Oβ̂`，`q=eᵀK_OO⁻¹e`、`ν=6−2=4`。目标位置的条件均值和基准协方差为

\[
\mu_T=X_T\hat\beta+K_{TO}K_{OO}^{-1}e,
\]

\[
D=X_T-K_{TO}K_{OO}^{-1}X_O,
\qquad C=K_{TT}-K_{TO}K_{OO}^{-1}K_{OT}+DA^{-1}D^T.
\]

在声明的平坦 β、尺度先验 `p(β,σ²)∝1/σ²` 下，输出多元 Student，**shape=`(q/ν)C`**；其预测 covariance 还需乘 `ν/(ν−2)`。趋势估计的不确定项 `DA⁻¹Dᵀ` 不能省略。K 的 shape 含完整已有 residual，不以两维码协方差替代。rank、SPD 或数值不可分辨残差失败时拒绝，不补选择性 variance floor。

这仍是可解释的小模型：它把同六读数用于当前曲线的偏移/斜率/尺度，而保留原相关结构。若它不如同预算幂律，说明被保留的 frozen shape 仍未提供足够有益增量；不应以“更接近原创新概念”为理由强行选它。

## 7. 先开发追平强控制，再一次性开放 expansion

以下门与 root 最新决定一致；记录规则并不等于已经满足：

- 新 dev 诊断只比较上节两个 K-shape 候选，所有十四个已冻结 mask 的结果完整报告。
- **选择只看固定 nearest-target 六读数布局**的三 recipe 宏 CRPS。两个候选差值在 `1e−12` 内时选 GP shape；不能在揭示后的十四布局中挑最优 policy 作为先验布局。
- 只有所选候选的 dev 宏 CRPS 点估计不高于幂律 Student nearest-target 控制 **0.04448968626222477**，才有理由另登记一次 expansion 实验。这只是开发准入门，不是统计非劣效性、可靠覆盖或论文达标的证明。
- 若没有追平，保留旧结果与失败，不消耗 final；继续调查有科学依据的模型边界或寻找适合的新资料。不得在同一小 dev 上无上限地加参数、换 score/位置直到过线。
- 若追平，将两候选中按规则确定的一个、固定布局、全部源码/输入/模型 hash、评分和独审写入新的实际 UTC 协议，**一次性预测此前未消费的三 expansion recipe、十五 runs**。原物理控制与冻结 GP/曲率参考仍同六点比较；先冻结预测并独审，再揭示其共同目标。不因结果改 recipe、温度 block、mask、阈值或随机种子。
- expansion 的读取是新的开发扩展证据；是否允许之后训练必须另记角色。四个 final recipe 的二十 runs 所有黏度继续保护，不能说它们已经验证或使用过。

只有三个 dev recipe，不足以论证广泛材料泛化或精确校准。我们也不必要求模型适用于一切材料，才承认局部材料研究的价值。当前需要的是把“追平强基线的具体领域/任务”做实，再判断额外机制是否值得顶会论证；代码与日志完善不能替代这项证据。
