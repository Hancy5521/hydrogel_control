# Curve repair checkpoint A — 9 November 2026

Source and recipe-level aggregate history for the frozen-MLST extension, new polymer-resin curve stress pilot, physical Student controls, failed early-update transfer, and failed universal-Kriging development diagnostic. This is research evidence, not a top-conference readiness claim. MLST/main is unchanged.

The full local package has 184 payload files, 16 byte-pinned original runtime dependencies, raw public source, frozen forecasts/targets, original failures, and all independent audits. Its ZIP SHA256 is recorded in LOCAL_PACKAGE_IDENTITY.json. An independently relocated copy passed seven saved-evidence audits. This public snapshot deliberately contains source and aggregates; it does not upload raw response rows or model states. To reproduce the saved numerical audits, use the complete local package rather than treating this source-only snapshot as a complete data bundle.

Data: [Zenodo19699588](https://doi.org/10.5281/zenodo.19699588), data CC BY 4.0. Native viscosity cP is converted to Pa s and then natural log. Three recipes/fifteen original runs are development; thirty-five future/final runs remain numerically unreleased. Published data use by other authors is not counted as consumption by this project.

Both positive and negative results are retained; no failed branch is retuned on these same three recipes.
