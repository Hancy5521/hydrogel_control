五、核查／复现（输出目录必须不存在）
安装requirements中版本。数据与预测均在H盘，核心只需NumPy/SciPy/threadpoolctl，matplotlib用于图。
复制本资源到任意位置后：
  python reproduce.py --mode metadata --output-dir H:/NEW_METADATA_CHECK
默认metadata模式只核源码/数据/原组计划，生成新路径的协议，不拟合、不评分。
若你明确要重复原研究计算：
  python reproduce.py --mode full --output-dir H:/NEW_OFFLINE_REPRODUCTION
full模式明确重复已消费的同一离线试验，自动生成带当前实际UTC的新复现记录，不覆盖原协议/预测/评分，不是独立确认。先prepare，再fit/freeze，最后score。没有调用LLM、新DFT或仪器。
若从公开Git获得的副本没有原始gzip：
  python fetch_pinned_data.py --output-dir H:/NEW_PUBLIC_DATA
  python reproduce.py --mode metadata --data-dir H:/NEW_PUBLIC_DATA --output-dir H:/NEW_METADATA_CHECK
fetch只用原Figshare稳定URL并核原bytes/SHA，复制5个已pin元数据。此处没有为验包重新下载数据。

原始协议含当时绝对路径，作为历史收据保留。移位复现请生成新的protocol，不要编辑旧文件然后声称它仍是原始预登记。数学近似、版本与浮点排序可能影响跨环境的精确动作；源环境和每步动作已完整保留用于定位。

六、指标怎样读
主终点是每表8个保守test身份组等权的warm标准化GaussianCRPS。四个随机seed是同组上的轨迹重复，不能当4套独立材料；两个数据源单独拟合，不是同权重跨域泛化。成本相同的是新增24个bundle，揭示格数24–37不等；初始UCSB47包、JARVIS29包单列。
UCSB目标rho/S/kappa，PF/zT/sigma整体隔离，前沿只找低kappa候选，不称完整热电性能优化。JARVIS目标e_form/gap/bulk是原DFT值，原生负bulk不删；寻找高bulk是原候选池检索，不称新合成材料。
原生缺失无可评真值，本轮完整案例上遮挡；选择偏差与转导可见X均保留。当前KG为每维5节点GH近似，不能叫完整高精度HV-KG。
