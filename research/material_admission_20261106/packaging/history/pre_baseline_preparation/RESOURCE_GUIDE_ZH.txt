先验证包完整性
在解压后的唯一短ASCII顶层目录打开终端：
  python verify_resources.py
如要一起检查下载ZIP成员及CRC：
  python verify_resources.py --zip "H:\PolymerReview\Material_Feedback_20261105T145420Z.zip"
校验器仅用Python标准库核SHA/尺寸/成员/CRC，不拟合模型、不计算材料评分。PACKAGE_MANIFEST.json列出每个有效文件的尺寸和SHA，自身除外。

四个复现模式（默认只准备）
  python reproduce.py --mode phase1-forecast --output-dir H:\MaterialReplay\p1_forecast --prepare-only
  python reproduce.py --mode phase2-forecast --output-dir H:\MaterialReplay\p2_forecast --prepare-only
不写--run也是只准备。准备会校验本地资源、写一个新的实际UTC复现协议和复现来源记录，生成命令但不调用科学模块、不解压性质JSON、不产生新材料实验。输出目录必须不存在且位于资源包之外。可把整个目录移动到别的盘，路径由本地RESOURCE_PATH_MAP.json重映射，不依赖旧H盘stage。

只有读者明确决定重放时，才将--prepare-only改为--run。预测完成后才可评分：
  python reproduce.py --mode phase1-score --forecast-reproduction H:\MaterialReplay\p1_forecast --output-dir H:\MaterialReplay\p1_score --prepare-only
  python reproduce.py --mode phase2-score --forecast-reproduction H:\MaterialReplay\p2_forecast --output-dir H:\MaterialReplay\p2_score --prepare-only
评分入口要求同阶段真实执行完成的外部预测目录、完整预测冻结和精确协议SHA；不能把prepared-only目录当作已完成预测。评分复用预测协议的原字节，另记新的评分UTC和批准收据，避免新时间戳破坏预测冻结绑定。历史科学协议和结果始终保留。此处的手动复现记录只授权重放已消费开发资料，不是原研究批准，也不是新独立确认。

GP/森林对照有独立的strong_baselines/README.txt、冻结模板及两步原始CLI。四模式wrapper不自动重跑这6次拟合。它们使用包内已经冻结的阶段2可见输入，不必重新解析gzip；任何重新运行均为开发集重放。只需评估现有成果时，直接读冻结评分和审计，完全不需要重放。
